## What the developers already said

<Checked version="V1.0.11" note="Friends Only as the default is the 10 May 2026 patch. VPN guidance is the pinned FAQ." />

The pinned FAQ, from the studio, is short:

- Windows PCs only, for now.
- No matchmaking. Steam friends only. Their Discord is [discord.gg/8GZwxBqhxN](https://discord.gg/8GZwxBqhxN) if you need people to play with.
- Solo is allowed and not recommended.
- Lobby Mode is Friends Only or Invite Only. It is not a public browser. Change it next to your profile on the main menu, or in Settings, General, Lobby Mode. Re-host after you change it. V1.0.11 corrected the default for new lobbies to Friends Only; the studio called the old default an oversight.
- Connection problems: do not use a VPN or other software that rewrites the connection. They use the Steam API for lobbies. The friend with the best connection and PC should host.

A June 2026 player thread matches the VPN line in practice: joins started working when Cloudflare WARP was turned off. That is one report, not a study. It is still the first network thing to try.

V1.0.30 also mentions network-code improvements. If one person never installed that update, you are debugging a version mismatch and calling it lag.

## Where the log actually is

The FAQ says: Windows key + R, type `appdata`, then go to `LocalLow\TENSTACK\Gamble With Your Friends` and send the file named Player. That shortcut opens the Roaming folder. LocalLow is its sibling. The reliable path is:

`%USERPROFILE%\AppData\LocalLow\TENSTACK\Gamble With Your Friends`

The log is the latest session. Grab it right after the failure. Send it to support@tenstack.se. Do not post account tokens or a private IP in a public thread.

There is also Pause Menu, Report A Bug, inside the game.
